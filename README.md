# FM Receiver using Arduino

A real-time FM receiver project designed to receive and process FM radio signals in the 88–108 MHz frequency range.

## 📌 Project Overview

This project presents an FM receiver system that captures FM radio signals, processes them, and produces an audio output. The project demonstrates practical concepts of analog communication, circuit design, signal processing, tuning, filtering, and audio amplification.

The proposed system combines analog front-end components with digital signal processing and microcontroller-based control to improve signal reception, audio quality, tuning precision, and usability.

## 🎯 Objectives

- Design and develop an FM receiver circuit.
- Receive FM signals in the 88–108 MHz frequency range.
- Amplify weak incoming radio signals.
- Filter unwanted noise and interference.
- Demodulate FM signals to recover audio.
- Provide clear audio output through an audio amplifier.
- Improve frequency tuning and station selection.
- Evaluate signal reception, audio quality, and power efficiency.

## 🔄 Working Principle

The antenna receives FM radio signals in the 88–108 MHz band. The received signal is amplified and filtered to reduce unwanted interference. The signal is then processed and demodulated to recover the original audio information.

The processed audio signal is converted and amplified before being delivered to a speaker or headphones. A microcontroller-based interface can be used for frequency tuning, station scanning, preset memory, signal strength indication, and power management.
